Como funcionam os alertas

A Malha avisa-te quando alguma coisa exige atenção. Os avisos aparecem sempre no painel (em Alertas). Se quiseres, também os recebes no Telegram e/ou no WhatsApp, sem teres o painel aberto.

Os canais só enviam mensagens: não recebem comandos, por isso ninguém consegue controlar os bots por lá. As mensagens dizem o bot, o par e o motivo (por exemplo "stop-loss"), nunca valores da carteira nem chaves.

Atenção: vê quando puderes, o bot já se protegeu sozinho. Alto: exige que faças alguma coisa (ou pelo menos que percebas o que se passou).

O que enviar e para onde

Sugestão: WhatsApp só para "alto", porque é o canal que mais te interrompe.

Telegram

Gratuito e o mais simples de configurar. Precisas do Telegram instalado no telemóvel.

  1. No Telegram, procura @BotFather, escreve /newbot e segue as perguntas. No fim ele dá-te um token (uma linha comprida com um : no meio).
  2. Abre a conversa com o teu bot novo e envia-lhe qualquer mensagem (por exemplo "olá"). Sem isto ele não te pode escrever.
  3. Descobre o teu id da conversa: procura @userinfobot e envia-lhe uma mensagem; ele responde com o teu número (Id).
  4. Cola os dois abaixo. Enviamos uma mensagem de teste antes de guardar.

WhatsApp

O WhatsApp não tem uma ligação oficial simples para uso pessoal. Há dois caminhos. Escolhe um:

CallMeBot o mais simples

Serviço gratuito de terceiros para uso pessoal. Recebes as mensagens no teu próprio WhatsApp. Como passa por eles, o CallMeBot vê o teu número e o texto dos alertas (nunca chaves nem valores da carteira). Pode deixar de existir.

WhatsApp Cloud API (Meta) oficial, mais trabalhoso

Serviço oficial. Exige conta de programador e uma app na Meta. Fora da janela de 24 h após uma resposta tua, só aceita mensagens a partir de um modelo aprovado. Mais estável, mas só compensa se já usas a plataforma Business.

{% endif %}
Formato internacional, com o indicativo do país (Portugal: +351).
Passos do CallMeBot
  1. Abre callmebot.com e procura a página "Free API WhatsApp Messages". Lá está o número do CallMeBot (muda de vez em quando, por isso não o escrevemos aqui).
  2. Guarda esse número nos contactos e envia-lhe, pelo WhatsApp, a frase de ativação que a página indica (uma frase do género "I allow callmebot to send me messages").
  3. Passados alguns minutos ele responde-te com uma chave (apikey). Cola-a abaixo.
Passos da Cloud API da Meta
  1. Em developers.facebook.com cria uma app do tipo Business e junta o produto WhatsApp.
  2. Em "API Setup" copia o Phone number ID e o token de acesso. O token de teste dura 24 h; para uso contínuo cria um token permanente (utilizador de sistema) no Business Manager.
  3. Junta o teu número à lista de destinatários permitidos e confirma-o com o código que recebes.
  4. Se as mensagens só chegarem quando tu escreveste há menos de 24 h, cria e aprova um modelo (template) com uma única variável no corpo e escreve o nome dele abaixo.
Deixa vazio para enviar texto normal (só funciona dentro das 24 h).
